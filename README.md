# FocusFlow — лаборатория фокуса

Статический трекер задач, привычек и времени. Откройте `index.html` двойным кликом.

Без сборки, библиотек и ES-модулей. Только шрифты загружаются из Google Fonts.

История оформляется по заданному плану: 39 ретроспективных коммитов 16–21 октября 2026. Фактическая разработка выполняется позднее.
