# FocusFlow design direction

A personal workbench with a midnight-blue navigation rail, paper workspace and a contrasting focus timer. The timer is the primary visual anchor; task rows and weekly rituals remain quiet and readable.

Palette: paper #F4F5F8, white #FFFFFF, ink #18233B, midnight #141E34, timer #202C4B, violet #4E50D8 and lavender #C2BBFF. Manrope carries headings and timer digits; DM Sans carries controls and body copy, with system fallbacks.

Progress is a single segmented strip. Inline SVG icons share a consistent stroke. An original breathing-wave drawing provides a gentle secondary accent without competing with the timer. Empty states offer useful actions, never invented activity.

Desktop: navigation | tasks, habits, insights | timer. Tablet: timer and breathing panel above tasks. Mobile: compact navigation and one column. Focus mode removes the surrounding workspace; Escape or Back restores it. Reduced-motion support, labelled controls, visible keyboard focus and native dialogs are retained.
